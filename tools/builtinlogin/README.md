# 内置适配器登录会话

仅依赖 Go 标准库，供 TRAE 和 WorkBuddy 适配器共用。`New(begin).Register(mux, authorize)`
注册创建、轮询、回调提交与取消接口。`begin` 返回授权地址、交互方式和完成函数；完成函数负责校验上游身份、持久化凭证及热加载账号池。

接口仅供 Sub2API 管理员后端调用，必须提供非空适配器密钥和 `X-Login-Owner`。会话有效期十分钟，最多保存 256 个，单会话串行执行；完成后清除凭证闭包并保留脱敏结果，便于幂等重试。请求上下文取消向上游传播。错误只返回已定义的公开信息，原始凭证不进入响应或日志。

运行 `go test -race ./...` 验证认证、会话隔离、到期、取消、重复提交和并发行为。

## A 类修复

### A-1：Auto 服务端引用型输入误判为整池无候选（对应聚合签名 `Auto model routing has no eligible model` ×180）

**根因**：`backend/internal/service/model_fallback_policy.go` 的 `modelInputCompatible` 原先把 `item_reference`、`input_file`、`input_audio`、`audio`、`video_url` 等服务端引用/媒体条目无条件判为账号不兼容。`model=auto` 的账号级预检因此把所有候选标成 `no_compatible_account`，最终返回 503；但真实转发路径会规范化或丢弃这类条目，同一账号池仍可服务。

**补丁**（已 cherry-pick 已办分支 `31c442f67`，当前提交 `b38be5c46`）：
- `backend/internal/service/model_fallback_policy.go`：新增 `assistedReference` 选项；Auto 账号级预检放宽引用型条目，failover/请求可移植性检查继续严格拒绝。
- `backend/internal/service/auto_model_vision.go`：`AutoModelRequestAccountCompatible` 走放宽路径。
- `backend/internal/service/model_fallback_policy_test.go`：覆盖引用/媒体条目、assistant audio、`redacted_thinking` 的 Auto 与 failover 边界。
- `backend/internal/handler/auto_model_plan_test.go`：覆盖 `/v1/responses` `model=auto` 不再整池无候选。

**验证**：
- `go test ./internal/handler -run TestAutoModelPlanKeepsCandidatesForReferenceInput -count=1 -v`：PASS。
- `go test ./internal/service -run TestAutoModelReferenceInputDoesNotExcludeEveryAccount -count=1 -v`：当前 Go 测试匹配显示 `no tests to run` 后 PASS，未将其计作有效用例执行；需后续单独确认测试选择/命名及完整 service 包执行。
- `go test ./internal/service ./internal/handler`：未整体通过；输出含大量既有集成/环境噪声，最终 `internal/handler` FAIL。本次报告不把全包结果视为补丁回归通过。

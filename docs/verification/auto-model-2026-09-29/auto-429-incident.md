## 本次修复

- HTTP 429 同时精确匹配 `code=3009` 和对应并发消息；支持直接、适配器包装、Responses 嵌套错误。余额不足、其他代码、回显输入不匹配。
- OpenAI 兼容适配器的已确认并发错误不进入持久化额度封禁路径；先寻找其他账号，无可用账号时沿用最多三次、每次两秒的请求内等待，仍失败则按原安全规则降级。
- Auto 观察记录复用服务端 request ID；缺少中间件 ID 时才生成随机 ID。
- 重放被阻断时将 `previous_response_id`、`conversation`、`nonportable_input`、`hosted_tools` 等类别写入日志及原请求错误链，保留原始上游错误，不记录提示词、工具参数或会话标识。
- 没有放宽服务端状态、托管工具、密文推理及已输出内容的重放限制。

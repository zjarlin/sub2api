## 降级与周期的实际含义

服务端 Auto 按当前请求生成的固定候选列表有限迭代，不递归重建候选链。同名模型可因来源平台不同出现多次；候选耗尽就返回失败。

Buddy 目录同步默认每 5 分钟执行一次，但同步不调用推理接口。后端每 6 小时检查目录刷新，快照有效期为 12 小时。原健康探测默认每账号每 168 小时选一个模型，每轮最多 10 项，因此并非全部模型每周验证一次。本机未安装 Buddy 常驻服务，不能以这些默认值证明用户 macOS 上已有周检任务运行。

## 源码修复

- 周期探测由每账号每周一个模型改为每个账号/模型对分别到期。默认 168 小时，每 15 分钟扫描最多 10 对，并发 3；已配置映射与同步目录均参与，重复条目合并。GPT、专用模型和已禁用探测账号沿用自动排除规则。
- 合并大小写和映射健康记录的最新检查时间，真实流量只推迟对应模型；成功和失败均推进队列。331 对的模拟测试在 34 批内完整覆盖。结果持久化失败、停机或账号不可调度仍会影响覆盖，周期不代表 SLA。
- 成功探测仅清除该模型之前的负面记录。比较失败记录、凭据、平台、类型及代理，防止旧成功覆盖新故障；与调度 outbox 原子提交。
- Auto 计划与模型目录使用同一分组快照和投影，错误账号保留但不可选，私有/禁用账号排除；无实际来源的展示模型标为 `source_missing`，不猜别名或伪造能力。
- 上述一致性覆盖账号配置、同步目录和静态默认投影，未覆盖任意外部 pinned/live manifest 或历史客户端缓存。线上 32 个缺失 ID 尚需部署后逐项复核，未证实逐项闭环。
- Codex Buddy 增加显式 `probe` 命令、供应商隔离的报告、模型身份差异检查。同步仍只发现目录，输出明确标注没有探测可用性。

# 模型档位与自动降级

管理入口：系统设置 → 网关服务 → 模型档位与自动降级。

配置存放在 `settings.model_fallback_policy`，通过管理端 `GET/PUT /api/v1/admin/settings/model-fallback` 读写。推荐配置通过 `GET /api/v1/admin/settings/model-fallback/preset` 获取，载入后需要保存。未保存配置时使用内置推荐；关闭开关后仅保留同名账号重试。通用设置的保存不会覆盖此独立配置。

每档包含名称与精确模型 ID，档位数组由高到低排列。同名账号重试耗尽后，先按该档的填写顺序尝试其他模型，再逐档往下；从较低档发起的请求不向上跳。别名需显式加入；未评级的模型不猜测档位。一次请求固定候选清单，每个模型最多进入一次，配置最多 12 档、64 个模型。客户端取消和既有超时仍立即生效。

## 推荐分档的公开依据

来源：[Artificial Analysis 模型榜单](https://artificialanalysis.ai/leaderboards/models)，读取日期 **2026-09-20**。采用该日期可见的 **Intelligence Index、每个模型最高已测推理强度**，每 10 分划一档。这是可修改的运维策略，不是评测方给出的等价能力认证，不代表具体编码任务、速度、价格或所有推理强度均相同。参考分数不会被用于放宽账号实际上下文上限，也不自动修改请求的推理强度。

| 推荐档位 | 公开模型名称及分数（评测条件） |
| --- | --- |
| AA 50+ | GPT-6 Astra 53（max） |
| AA 40–49 | GPT-5.6 Sol 47（max）、GLM-5.3 45（max）、Kimi K3 44（max）、GPT-5.6 Terra 42（max）、GLM-5.3-Flash 42 |
| AA 30–39 | DeepSeek V4.1 Flash 39（max）、GPT-5.6 Luna 37（max）、Agnes 3.0 Flash 36*、Agnes 2.5 Pro Beta 35*、Qwen3.8 27B 34（xhigh）、GPT-5.3 Codex 33*（xhigh） |
| AA 20–29 | Agnes 2.5 Pro Alpha 27* |

星号沿用来源页面标记，不能据此声称与未标星项目具有同等评测覆盖。推荐仅收录本次已确认上游目录中存在、且能明确对应公开评测的 ID。`z-ai/`、`moonshotai/` 路径 ID 与各自对应版本放在同档。无法证明版本对应的 `deepseek-v4-pro`（榜单为 0813）、`gpt-5.5`（榜单展示的 Instant 不是同一明确 ID）、`gpt-5.6` 及旧版 Flash 等不自动评级。管理员可根据已知映射、实测与业务要求补齐。

当前最高档只有一个已匹配模型；没有同档候选时直接进入下一档。新模型可手动加入，不在请求路径抓取榜单。

## 执行边界

- 覆盖 OpenAI 兼容账号池的 HTTP Responses、Chat Completions、Messages 入口及其 SSE 模式，沿用现有账号限流、并发、渠道限制、模型能力与利润检查；不跨 API Key 分组或绕开平台路由。专用图片、向量及有状态 WebSocket 不套用文本能力档位。
- 服务端会话引用、托管工具状态、不可移植的文件/音视频/加密推理内容和已输出实质内容不跨模型重放。普通函数工具保留输入原文。
- 目录预筛选和实际选号后均检查已知上下文、最大输出、推理强度及原生图片能力。上下文使用请求字节数加输出预算保守估算，不截断历史；上游未声明的能力不能当作已验证保证。上游仍可能拒绝未知的协议差异。
- 中间失败、模型变更和账号快照都保留在监控链。请求模型用于请求归属，实际模型用于转发与降级后的计费，响应保留真实模型；附加 `X-Sub2api-Requested-Model`、`X-Sub2api-Fallback-Model` 响应头（响应头尚未提交时）。
- 可重放失败才进入降级；请求格式、权限、计费和明确停止重试的错误仍终止。所有兼容候选耗尽后必须返回最终错误，不伪造成功。

## 验证

回归测试覆盖同名账号先行、同档优先、跨多档成功、全部耗尽、禁用策略、未知模型、重复配置、状态引用、能力不兼容、取消及持久化读写。前端验证配置载入、编辑排序、校验、保存及模型链展示。
